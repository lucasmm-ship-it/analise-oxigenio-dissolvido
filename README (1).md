
# Análise de Oxigênio Dissolvido em Águas Brasileiras

## 1. Sobre o projeto

Este projeto apresenta uma análise exploratória de dados de oxigênio
dissolvido em estações de monitoramento de águas brasileiras.

A análise utiliza Python para organizar, explorar, visualizar e
comparar dados ambientais, com destaque para o Maranhão.

## 2. Objetivo

Investigar os dados de oxigênio dissolvido e comparar as médias
registradas no Maranhão com as demais unidades da Federação em 2020.

## 3. Base de dados

Fonte: Sistema Nacional de Informações sobre Recursos Hídricos (SNIRH).

A base contém 5.642 registros e 139 colunas, incluindo informações
sobre estações de monitoramento, localização e medições anuais.

## 4. Ferramentas utilizadas

- Python
- Google Colab
- Pandas
- Matplotlib
- SciPy

## 5. Principais resultados

- Média do Maranhão em 2020: 6,84.
- Média das demais UFs: 6,62.
- Teste t de Welch: valor-p de 0,6766.
- Não foram encontradas evidências estatísticas suficientes de
  diferença entre as médias dos dois grupos.

## 6. Conclusão

A comparação não identificou diferença estatisticamente significativa
entre as médias de oxigênio dissolvido dos grupos analisados em 2020.
A análise também revelou maior dispersão dos valores nas estações
maranhenses.
